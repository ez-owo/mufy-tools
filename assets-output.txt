# 【Assets｜资产终端】
Assets是{{user}}在本卡中的自动资产账本。它不是现实金融核验，也不需要{{user}}逐项确认；AI必须根据已经建立的设定、剧情事实和系统资金自动维护。

固定结构：
```xml
<Assets>
<Cash>流动资金</Cash>
<PropertyTotal>房产合计</PropertyTotal>
<PropertyList>房产明细</PropertyList>
<OtherTotal>其他资产合计</OtherTotal>
<OtherList>其他资产明细</OtherList>
<DebtTotal>负债合计</DebtTotal>
<DebtList>负债明细</DebtList>
<Net>净资产</Net>
<Flow1>最近第1条流水</Flow1>
<Flow2>最近第2条流水</Flow2>
<Flow3>最近第3条流水</Flow3>
<Flow4>最近第4条流水</Flow4>
<Flow5>最近第5条流水</Flow5>
</Assets>
```

固定顺序：`Cash → PropertyTotal → PropertyList → OtherTotal → OtherList → DebtTotal → DebtList → Net → Flow1 → Flow2 → Flow3 → Flow4 → Flow5`

## 自动初始化
- 有上一轮Assets时，上一轮完整Assets是唯一期初账本，再根据本轮发生的经济变化更新。
- 没有可继承Assets时，先读取当前已经建立的{{user}}职业、收入层级、生活状态、房产/车辆/投资/负债等事实，并自动形成首次账本。
- 设定明确存在某项资产或负债、但没有精确金额时，AI根据当前时代、城市、职业与生活层级给出保守合理估值，并在明细里标注`估值`；后续出现精确金额时，用精确值替换估值。
- 如果当前设定完全没有提供任何个人资产信息，不追问、不等待确认，直接把本卡账本初始化为：`Cash ¥0.00 / PropertyTotal ¥0.00 / PropertyList 暂无 / OtherTotal ¥0.00 / OtherList 暂无 / DebtTotal ¥0.00 / DebtList 暂无 / Net ¥0.00 / Flow1—Flow5 暂无`。
- 上述`¥0.00`表示本卡当前纳入账本的起始值，不宣称{{user}}现实中没有其他资产。
- Assets中禁止使用`未确认`、`待确认`、`未登记`、`计入值未定`、`（AI填充）`作为持续状态，也禁止要求{{user}}先确认才能更新。

## 自动更新
以下事件一旦在剧情中真实发生，本轮Assets必须同步变化：
- 明确收到工资、奖金、退款、转账、礼金或其他现金收入；
- 明确发生消费、付款、转账、赔偿或其他现金支出；
- 明确获得、出售、赠与、损失房产或其他资产；
- 明确新增、偿还或免除负债；
- 剧情中出现足以改变既有估值的可靠信息。

不得凭空创造经济事件，但已经发生的经济事件不得漏记。

### Cash
- `Cash新值 = Cash旧值 + 本轮已发生现金流入 - 本轮已发生现金流出`。

### Property / Other / Debt
- 房产：`名称｜产权/份额｜¥金额或估值¥金额｜状态`
- 其他资产：`名称｜类别/份额｜¥金额或估值¥金额｜状态`
- 负债：`名称｜剩余¥金额或估值¥金额｜用途/状态`
- 多项用`；`分隔；没有项目写`暂无`。
- 已建立项目不得无原因消失；精确金额出现后不得再退回估值。

### Net
每轮自动重算：
`Net = Cash + PropertyTotal + OtherTotal - DebtTotal`
所有总额统一使用当前账本中的精确值或估值，因此Net始终输出一个可计算金额，不再输出`待确认`。

## 最近5条流水
`Flow1最新 → Flow2 → Flow3 → Flow4 → Flow5最旧`
格式：`YYYY-MM-DD HH:mm｜类型｜±¥金额/资产¥金额｜摘要｜余额/总额`

例如：
`2026-08-24 17:48｜收款｜+¥2,832.00｜零花钱｜现金¥2,832.00`

规则：
- 新流水插入Flow1；原Flow1→Flow2，依次下移；超过5条删除最旧一条。
- 没有历史流水统一写`暂无`。
- 流水末尾Cash必须与本轮`<Cash>`一致。
